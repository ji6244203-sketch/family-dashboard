# 우리 가족 보드 🎀

거실 태블릿에 띄워 두는 가족 대시보드. 단일 `index.html` 하나로 동작하며, 빌드가 필요 없습니다.

## 무엇이 있나요

| --- | --- |

## 저장 방식

- 모든 기록은 **이 기기의 브라우저 `localStorage`** 에만 저장됩니다(키: `family-dashboard.v1`, 저장 형식 `v: 2`). 서버로 보내는 개인정보는 없습니다.
- 날씨만 Open-Meteo API(전주 좌표)를 조회합니다.
- 매일 자정이 지나면 앱을 열거나 화면이 켜질 때: 등원 체크가 새로 시작되고, 달력은 오늘 날짜로 돌아갑니다.
  **지난 날짜의 일정은 지우지 않고 달력에 그대로 남습니다**(지난 일정도 다시 볼 수 있게). `매일 반복` 일정은 날짜와 상관없이 모든 날에 보입니다.
- 일정의 완료 표시(✓)는 **날짜별로** 저장됩니다. 같은 `매일 반복` 일정이라도 어제 완료와 오늘 완료는 따로이고, 120일이 지난 완료 표시만 자동으로 정리됩니다.
- 학습 체크는 날짜별로 남고 60일이 지난 기록은 자동으로 정리됩니다.
- 저장값을 완전히 처음 상태로 되돌리려면 브라우저 개발자도구 콘솔에서
  `localStorage.removeItem('family-dashboard.v1')` 후 새로고침하면 됩니다. (일정은 빈 상태로, 학습은 요일별 기본 9개로 시작합니다.)
- 이름을 바꾸기 전 버전에서 쓰던 이 기기의 기록(`이설이`/`이설`)은 앱을 열 때 자동으로 `설`로 바뀝니다.
- 그림 없는 예전 5개 기본 항목(`양치·세수하기` 등)으로 저장된 기기는 앱을 다시 여는 것만으로
  **새 8개 그림 항목으로 자동 전환**됩니다(저장 버전 `clVersion: 2`). 직접 추가했던 항목은 그림을 새로 붙여 뒤에 남습니다.
- **달력으로 바뀌기 전 저장값도 그대로 살아납니다**(저장 버전 `schedVersion: 3`):
  날짜 없이 저장돼 있던 일정은 **오늘 날짜** 일정이 되고, 예전 `완료한 날짜` 하나짜리 표시는 그 날짜의 완료로 옮겨집니다. 직접 추가한 일정은 지우지 않습니다.
  예전 버전이 첫 방문에 넣어 두던 예시 일정(`설 등원` 08:30 · `설 하원` 16:00)은 `schedVersion: 2` 때 한 번 정리됐고, 지금은 다시 건드리지 않습니다.
- 이 개편 전 기록(학습 탭이 없던 저장값)은 앱을 여는 것만으로 **학습 체크리스트 기본값이 더해지고**
  등원 체크·가족 일정·메모는 그대로 남습니다(`v: 2`, `learnVersion: 1`).

## 설정 바꾸기 (`index.html` 안에서)

- **아이 이름**: `설` — 체크리스트 제목, 축하 배너, 구성원 필터·일정 추가 칩에 나옵니다.
  다른 이름으로 바꾸려면 `index.html`에서 `설`을 찾아 바꾸면 됩니다(일정의 저장된 구성원 값도 함께).
- **등원 목표 시각 / 막대 구간**: `START_MIN`(기본 06:30) · `GOAL_MIN`(기본 08:15) · `GOAL_LABEL`.
- **가족 구성원**: `MEMBERS` 배열과 `WHO_KEY`(+ `index.html`의 필터 칩·일정 추가 칩·색 클래스 `.who-*`, `.tag.t-*`, 달력 점 `.cdots i.d-*`).
- **등원 체크리스트 기본 항목**: `DEFAULT_CHECK` 배열(항목 이름 + 그림 이모지). 첫 방문 시에만 적용되고,
  이미 열어 본 기기는 위의 자동 전환을 거칩니다. 항목 이름에 맞는 그림은 `ICON_HINTS`에서 찾습니다.
- **학습 기본 항목**: `DEFAULT_LEARN` 배열(9개). 첫 방문(학습 기록이 없는 기기)의 월~일 모든 요일에 들어갑니다.
- **달력**: `monthCells()` 가 월요일 시작 6주(42칸)로 칸을 만듭니다. 일요일 시작으로 바꾸려면 `offset` 계산을 `first.getUTCDay()` 로.
- **저장 버전**: 기본 항목이나 배치를 바꿀 때는 `CL_VERSION`/`LEARN_VERSION`/`SCHED_VERSION`을 1씩 올리고
  `loadState()` 안의 전환 규칙을 함께 고치면, 이미 열어 본 기기도 새 항목으로 바뀝니다.

## 로컬에서 열어 보기

```bash
cd projects/family-dashboard
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

> `file://` 로 열면 브라우저가 날씨 요청과 localStorage 를 막을 수 있습니다. 로컬 서버로 열어 주세요.

## 태블릿에 앱처럼 올리기 (GitHub Pages)

1. 이 폴더의 `index.html`, `README.md`, `.gitignore` 를 저장소 루트에 올립니다.
2. 저장소 → Settings → Pages → Branch: `main` / root → Save.
3. 태블릿 브라우저에서 `https://<계정>.github.io/<저장소>/` 를 연 뒤 **홈 화면에 추가**.
4. 앱처럼 전체 화면으로 뜨도록 `apple-mobile-web-app-capable`, `mobile-web-app-capable`, `theme-color` 메타 태그가 들어 있습니다.

## 검증한 것 (2026-11-24, Chromium · Asia/Seoul · 1280×800 · 전 항목 통과)

- 태블릿 가로 1280×800: 세로·가로 스크롤 0, 세 탭 모두 한 화면, 콘솔 에러 0건
- 오늘 · 등원: `오늘의 학습` 요약 카드 없이 등원 체크리스트만 화면 전체 폭(타일 4개 294px)으로,
  체크·진행률·배지, **이름+그림 수정 시트**(이모지 29종 + 직접 입력), 항목 추가, 삭제 후 되돌리기,
  모두 완료 시 축하 배너 + 막대 가득 참 + `오늘 준비 완료!`
- 가족 일정: 이번 달 달력(월요일 시작 6주) + 오늘 분홍 원 표시 + 오늘 일정 목록이 한 화면,
  `◀`/`▶` 로 12월 이동 → 12월 4일 선택 → `＋ 일정 추가`(날짜 기본값 12월 4일) → 목록·달력 점·건수 반영,
  ✏️ 수정, ✓ 완료(그 날짜에만), `매일 반복` 일정이 다른 날에도 보이고 완료는 날짜별로 따로,
  삭제 후 되돌리기, `오늘로` 복귀. 새로고침 후에도 일정·완료 표시 유지
- 저장값 마이그레이션: `schedVersion: 2` 저장값(날짜 없는 일정 · 문자열 `doneOn`)을 열면
  일정 3건 모두 남고, 날짜 없는 일정은 오늘로, 완료 표시는 날짜 맵으로 옮겨짐
- 학습 탭: 요일 7개 선택(오늘 표시), 요일별 항목 추가/수정/삭제가 그 요일에만 적용, 날짜별 체크 저장
- 아이 이름은 `설` 하나로(화면에 `이설` 없음), 출산 디데이 없음(화면 어디에도 `D-` 없음)
