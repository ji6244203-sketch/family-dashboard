# 우리 가족 보드 🏡

거실 태블릿에 띄워 두는 가족 대시보드. 단일 `index.html` 하나로 동작하며, 빌드가 필요 없습니다.

## 무엇이 있나요

| 영역 | 내용 |
| --- | --- |
| 상단 | 실시간 시계(시:분), 오늘 날짜·요일(한국어), 전주 날씨(현재 기온 / 최저·최고 / 강수확률, 비·눈이 오면 우산·길 안내) |
| 왼쪽 카드 | 🎒 설 등원 체크리스트 — 큰 터치 체크, 진행률 바, 모두 완료 시 축하 배너, 항목 추가·삭제, 자정 자동 초기화 + `오늘 초기화` |
| 오른쪽 카드 | 📅 오늘의 가족 일정 — 구성원별 색 구분과 필터, 일정 추가(시간·제목·구성원·오늘만/매일 반복), 완료 체크, 삭제 |
| 하단 | 🍽 오늘 저녁 메뉴 · 가족 한 줄 메모 — 탭해서 바로 쓰고 저장 |

## 저장 방식

- 모든 기록은 **이 기기의 브라우저 `localStorage`** 에만 저장됩니다(키: `family-dashboard.v1`). 서버로 보내는 개인정보는 없습니다.
- 날씨만 Open-Meteo API(전주 좌표)를 조회합니다.
- 매일 자정이 지나면 앱을 열거나 화면이 켜질 때: 체크리스트가 새로 시작되고, 지난 `오늘만` 일정은 정리되며, `매일 반복` 일정은 체크가 풀린 채로 남습니다.
- 저장값을 완전히 처음 상태로 되돌리려면 브라우저 개발자도구 콘솔에서
  `localStorage.removeItem('family-dashboard.v1')` 후 새로고침하면 됩니다. (예시 일정 2개가 다시 생깁니다.)
- 이름을 바꾸기 전 버전에서 쓰던 이 기기의 기록(`이설이`/`이설`)은 앱을 열 때 자동으로 `설`로 바뀝니다.

## 설정 바꾸기 (`index.html` 안에서)

- **아이 이름**: `설` — 체크리스트 제목, 축하 배너, 구성원 필터·일정 추가 칩, `예시 일정`(`설 등원` / `설 하원`)에 나옵니다. 다른 이름으로 바꾸려면 `index.html`에서 `설`을 찾아 바꾸면 됩니다(일정의 저장된 구성원 값도 함께).
- **체크리스트 기본 항목**: `DEFAULT_CHECK` 배열 (첫 방문 시에만 적용).
- **예시 일정**: `freshState()` 안의 `schedule` 배열 (첫 방문 시에만 적용).

## 로컬에서 열어 보기

```bash
cd projects/family-dashboard
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

> `file://` 로 열면 브라우저가 날씨 요청을 막을 수 있습니다. 로컬 서버로 열어 주세요.

## 태블릿에 앱처럼 올리기 (GitHub Pages)

1. 이 폴더의 `index.html`, `README.md`, `.gitignore` 를 저장소 루트에 올립니다.
2. 저장소 → Settings → Pages → Branch: `main` / root → Save.
3. 태블릿 브라우저에서 `https://<계정>.github.io/<저장소>/` 를 연 뒤 **홈 화면에 추가**.
4. 앱처럼 전체 화면으로 뜨도록 `apple-mobile-web-app-capable`, `mobile-web-app-capable`, `theme-color` 메타 태그가 들어 있습니다.

## 검증한 것 (2026-11-17, Chromium · Asia/Seoul · 59개 항목 전부 통과)

- 태블릿 가로 1280×800: 스크롤 없이 한 화면(세로·가로 스크롤 0), 2컬럼, 콘솔 에러 0건
- 태블릿 세로 800×1280: 1컬럼으로 전환, 가로 스크롤 없음(세로는 자연스럽게 스크롤)
- 브라우저 주소창으로 높이가 줄어든 1280×720: 스크롤 없이 버튼까지 도달
- 상단 헤더는 시계·날짜 + 전주 날씨만: 출산 디데이 뱃지·설정 팝오버 없음(화면 어디에도 `D-` 없음)
- 아이 이름은 `설` 하나로: 체크리스트 제목, 축하 배너, 필터·일정 칩, 예시 일정, 화면 문구에 `이설` 없음
- 시계는 한 자리 분도 두 자리로 (`15:04`)
- 체크 / 추가 / 삭제 / 되돌리기 / 초기화, 모두 완료 시 축하 배너
- 일정 추가·완료·삭제·구성원 필터, 예시 일정은 첫 방문에만 생성
- 메모 저장, 새로고침 후 모든 기록 유지(localStorage)
- 날짜가 바뀌면 체크 자동 초기화, 지난 `오늘만` 일정 정리, `매일 반복` 일정 유지
- 예전 이름(`이설이`/`이설`)으로 저장된 기록·필터가 `설`로 자동 변경
- 날씨 API 실패 시 문구만 조용히 바뀌고 나머지 기능은 그대로 동작
