# 우리 가족 보드 🏡

거실 태블릿에 띄워 두는 가족 대시보드. 단일 `index.html` 하나로 동작하며, 빌드가 필요 없습니다.

## 무엇이 있나요

| 영역 | 내용 |
| --- | --- |
| 상단 | 실시간 시계(시:분), 오늘 날짜·요일(한국어), 전주 날씨(현재 기온 / 최저·최고 / 강수확률, 비·눈이 오면 우산·길 안내) |
| 왼쪽 카드 | 🎒 설 등원 체크리스트 — 8개 기본 항목(화장실가기(소변)·아침식사·영양제·양치질·세수·로션·옷갈아입기·가방챙기기)을 글자를 못 읽어도 알아볼 수 있는 **큰 그림(이모지) 2열 카드 타일**으로 배치. 큰 터치 체크, 진행률 바, 모두 완료 시 축하 배너, 항목 추가(추가 항목에도 그림 자동 붙음)·삭제, 자정 자동 초기화 + `오늘 초기화` |
| 오른쪽 카드 | 📅 오늘의 가족 일정 — 구성원별 색 구분과 필터, 일정 추가(시간·제목·구성원·오늘만/매일 반복), **카드(시간·제목)를 탭하거나 ✎ 을 눌러 바로 수정**(같은 시트가 “일정 수정” 모드로 열림 · 시트 안에서 삭제도 가능), 완료 체크(✓), 삭제(✕). 첫 방문에는 일정 없이 빈 상태로 시작 |
| 하단 | 🍽 오늘 저녁 메뉴 · 가족 한 줄 메모 — 탭해서 바로 쓰고 저장 |

## 저장 방식

- 모든 기록은 **이 기기의 브라우저 `localStorage`** 에만 저장됩니다(키: `family-dashboard.v1`). 서버로 보내는 개인정보는 없습니다.
- 날씨만 Open-Meteo API(전주 좌표)를 조회합니다.
- 매일 자정이 지나면 앱을 열거나 화면이 켜질 때: 체크리스트가 새로 시작되고, 지난 `오늘만` 일정은 정리되며, `매일 반복` 일정은 체크가 풀린 채로 남습니다.
- 저장값을 완전히 처음 상태로 되돌리려면 브라우저 개발자도구 콘솔에서
  `localStorage.removeItem('family-dashboard.v1')` 후 새로고침하면 됩니다. (일정은 빈 상태로 시작합니다.)
- 이름을 바꾸기 전 버전에서 쓰던 이 기기의 기록(`이설이`/`이설`)은 앱을 열 때 자동으로 `설`로 바뀝니다.
- 그림 없는 예전 5개 기본 항목(`양치·세수하기` 등)으로 저장된 기기는 앱을 다시 여는 것만으로
  **새 8개 그림 항목으로 자동 전환**됩니다(저장 버전 `clVersion: 2`). 직접 추가했던 항목은 그림을 새로 붙여 뒤에 남습니다.
- 예전 버전이 첫 방문에 넣어 두던 예시 일정(`설 등원` 08:30 · `설 하원` 16:00)은 앱을 다시 여는 것만으로
  **한 번 정리**됩니다(저장 버전 `schedVersion: 2`). 직접 추가한 일정은 그대로 남습니다.

## 설정 바꾸기 (`index.html` 안에서)

- **아이 이름**: `설` — 체크리스트 제목, 축하 배너, 구성원 필터·일정 추가 칩에 나옵니다.
  다른 이름으로 바꾸려면 `index.html`에서 `설`을 찾아 바꾸면 됩니다(일정의 저장된 구성원 값도 함께).
- **체크리스트 기본 항목**: `DEFAULT_CHECK` 배열(항목 이름 + 그림 이모지). 첫 방문 시에만 적용되고,
  이미 열어 본 기기는 위의 자동 전환을 거칩니다. 항목 이름에 맞는 그림은 `ICON_HINTS`에서 찾습니다.
- **체크리스트 저장 버전**: 기본 항목이나 배치를 바꿀 때는 `CL_VERSION`을 1씩 올리고
  `loadState()` 안의 전환 규칙을 함께 고치면, 이미 열어 본 기기도 새 항목으로 바뀝니다.
- **예시 일정**: 없음 — 첫 방문에는 일정이 비어 있고, `freshState()` 의 `schedule` 배열이 빈 배열입니다.
  기본 일정을 넣고 싶으면 `freshState()` 의 `schedule` 에 넣은 뒤 `SCHED_VERSION` 을 1 올리고,
  `loadState()` 의 마이그레이션 규칙도 함께 정리하면 됩니다.

## 로컬에서 열어 보기

```bash
cd projects/family-dashboard
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

> `file://` 로 열면 브라우저가 날씨 요청을 막을 수 있습니다. 로컬 서버로 열어 주세요.

## 태블릿에 앱처럼 올리기 (GitHub Pages)

1. 이 폴더의 `index.html`, `README.md`, `.gitignore` 를 저장소 루트에 올립니다.
2. 저장소 → Settings → Pages → Branch: `main` / root → Save.
3. 태블릿 브라우저에서 `https://<계정>.github.io/<저장소>/` 를 연 뒤 **홈 화면에 추가**.
4. 앱처럼 전체 화면으로 뜨도록 `apple-mobile-web-app-capable`, `mobile-web-app-capable`, `theme-color` 메타 태그가 들어 있습니다.

## 검증한 것 (2026-11-17, Chromium · Asia/Seoul · 110개 항목 전부 통과)

- 태블릿 가로 1280×800: 스크롤 없이 한 화면(세로·가로 스크롤 0), 2컬럼, 콘솔 에러 0건
- 등원 체크리스트: 요청한 8개 항목이 순서대로, 큰 그림(🚽🥣💊🪥🧼🧴👕🎒)과 함께 2열(4행×2열) 타일로 표시
- 항목 추가 시 새 항목에도 이름에 맞는 그림이 자동으로 붙음(예: 마스크 챙기기 → 😷), 삭제·되돌리기·초기화·축하 배너
- 그림 없는 예전 5개 항목으로 저장된 기기: 새로고침만으로 8개 그림 항목으로 자동 전환(`clVersion: 2`),
  직접 추가했던 항목은 보존, 전환은 한 번만 적용
- **첫 방문: 일정 0건** — 예시 일정(`설 등원`/`설 하원`) 없이 "오늘 일정이 아직 없어요" 안내로 시작
- **예전 샘플 일정 정리**: `schedVersion` 없는 기기를 열면 `설 등원`(08:30)·`설 하원`(16:00)만 1회 지우고,
  직접 추가한 일정과 완료 표시는 그대로. 한 번 정리한 뒤 다시 넣은 일정은 지우지 않음
- **일정 직접 수정**: 카드의 시간·제목을 탭하거나 ✎ 을 누르면 같은 시트가 “일정 수정” 모드로 열리고
  시간·제목·구성원·반복이 미리 채워짐 → 고쳐서 저장하면 카드·저장값에 반영, 새로고침 후에도 유지(일정 수가 늘지 않음)
- **시트 안 삭제**(`🗑 이 일정 지우기`)·카드 ✕ 삭제 모두 동작하고 되돌리기 토스트 제공
- **버튼 배치**: ✎·✓·✕ 가 각각 40px 이상, 서로 겹치지 않고 화면에서 실제로 눌림(완료 원형 버튼과 삭제 ✕ 분리)
- 빈 제목은 저장되지 않고 시트가 유지됨, 필터가 걸린 상태에서 다른 구성원으로 수정해도 결과가 보이도록 필터 자동 해제
- 태블릿 세로 800×1280: 1컬럼으로 전환, 가로 스크롤 없음(세로는 자연스럽게 스크롤)
- 브라우저 주소창으로 높이가 줄어든 1280×720: 스크롤 없이 버튼까지 도달
- 상단 헤더는 시계·날짜 + 전주 날씨만: 출산 디데이 뱃지·설정 팝오버 없음(화면 어디에도 `D-` 없음)
- 아이 이름은 `설` 하나로: 체크리스트 제목, 축하 배너, 필터·일정 칩, 화면 문구에 `이설` 없음
- 시계는 한 자리 분도 두 자리로 (`15:04`)
- 일정 추가·완료·삭제·구성원 필터, 메모 저장, 새로고침 후 모든 기록 유지(localStorage)
- 날짜가 바뀌면 체크 자동 초기화, 지난 `오늘만` 일정 정리, `매일 반복` 일정 유지
- 예전 이름(`이설이`/`이설`)으로 저장된 기록·필터가 `설`로 자동 변경
- 날씨 API 실패 시 문구만 조용히 바뀌고 나머지 기능은 그대로 동작
